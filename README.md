# AI Level Design Assistant

AI 关卡设计助手是一个面向 2D 游戏关卡设计的 AI 辅助工具。

项目的核心目标不是制作一个通用聊天机器人，而是围绕游戏策划工作流，帮助用户根据关卡类型、场景、目标、难度、敌人和核心机制等参数，快速生成结构化的关卡设计方案，并提供评分与优化建议。

本项目主要用于探索 AI 在游戏关卡设计中的辅助价值，适合作为游戏策划、技术策划或 AI 应用方向的作品集项目。

---

## 项目背景

在进行 2D 游戏关卡设计练习时，关卡策划通常需要反复思考以下内容：

* 玩家目标是否清晰
* 地图区域是否合理
* 路线选择是否有差异
* 敌人配置是否符合难度
* 奖励是否能引导玩家探索
* 关卡节奏是否有起伏
* 失败条件是否合理

这些内容如果完全手动编写，会消耗大量时间。

因此，本项目尝试将大语言模型引入关卡设计流程，让 AI 按照固定策划模板生成关卡方案，并通过评分系统检查方案质量，帮助策划更快完成初稿和修改方向。

## 项目功能

### 1. 关卡方案生成

用户填写基础参数后，系统会调用 AI 生成完整的关卡设计方案。

支持输入内容包括：

* 关卡类型
* 游戏类型
* 关卡场景
* 玩家目标
* 关卡难度
* 敌人类型
* 核心机制
* 美术风格
* 预计游玩时长

AI 输出内容包括：

* 关卡主题
* 玩家目标
* 地图区域划分
* 路线设计
* 敌人配置
* 奖励配置
* 失败条件
* 玩家体验节奏
* 交互物与机制设计
* 风险收益设计
* 设计意图

---

### 2. 多类型关卡模板

项目目前支持 5 种 2D 关卡类型：

| 关卡类型      | 设计重点                     |
| --------- | ------------------------ |
| 2D 潜入关卡   | 路线选择、敌人巡逻、掩体分布、警报机制、风险收益 |
| 2D 平台跳跃关卡 | 平台布局、跳跃节奏、陷阱配置、检查点、难度曲线  |
| 2D 解谜关卡   | 谜题目标、机关设计、信息提示、解谜步骤、错误反馈 |
| 2D 动作战斗关卡 | 战斗空间、敌人波次、敌人组合、补给配置、战斗节奏 |
| 2D 探索冒险关卡 | 区域连接、探索路线、隐藏奖励、环境叙事、支线目标 |

不同关卡类型会使用不同的 Prompt 模板，使生成结果更贴合对应玩法。

---

### 3. AI 自动评分

关卡方案生成后，系统会再次调用 AI，对方案进行评审。

评分总分为 100 分，评分内容会根据关卡类型动态调整。例如：

* 目标是否明确
* 路线选择是否清晰
* 风险收益是否成立
* 敌人配置是否合理
* 隐藏路线是否有探索价值
* 玩家体验节奏是否合理

评分结果包含：

* 总评分
* 分项评分表
* 当前方案存在的问题
* 可执行的优化建议
* 是否适合继续完善为作品集案例

---

### 4. 一键优化

用户可以根据评分结果，对当前关卡方案进行一键优化。

优化重点包括：

* 让关卡目标更明确
* 让路线差异更清晰
* 调整敌人与障碍分布
* 提高隐藏路线的探索价值
* 强化奖励与风险之间的关系
* 改善关卡节奏

优化后的方案会保留原有关卡方向，但会针对评分中指出的问题进行修改。

---

### 5. 历史记录

每次生成的关卡方案都会保存到本地 JSON 文件中。

保存内容包括：

* 用户输入参数
* 生成的关卡方案
* AI 评分结果
* 创建时间

用户可以在页面中查看历史记录，方便后续整理和对比不同方案。

---

### 6. Markdown 导出

项目支持将当前关卡方案导出为 Markdown 文档。

导出内容包括：

* 用户输入参数
* AI 生成的关卡方案
* AI 评分结果
* 问题分析
* 优化建议

该功能主要用于后续整理作品集文档或关卡策划案。

## 本地运行

### 1. 克隆项目

```bash
git clone <your-repo-url>
cd ai-level-design-assistant
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

复制环境变量模板：

```bash
cp .env.example .env
```

在 `.env` 文件中填写 DeepSeek API Key：

```text
DEEPSEEK_API_KEY=your_api_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

### 4. 启动项目

```bash
streamlit run app.py
```

启动后，浏览器会打开本地页面：

```text
http://localhost:8501
```

## Streamlit Cloud 部署

本项目可以部署到 Streamlit Community Cloud，生成公网访问链接。

### 1. 上传到 GitHub

确保项目根目录包含以下文件：

```text
app.py
requirements.txt
README.md
.env.example
.gitignore
prompts/
services/
docs/
data/
```

不要上传以下文件：

```text
.env
.streamlit/secrets.toml
.venv/
venv/
__pycache__/
*.pyc
```

### 2. 创建 Streamlit 应用

进入 Streamlit Community Cloud 后：

1. 点击 New app
2. 选择 GitHub 仓库
3. 选择 main 分支
4. 设置主文件路径为 `app.py`
5. 点击 Deploy

如果项目被放在子文件夹中，需要将主文件路径改成：

```text
子文件夹名/app.py
```

### 3. 配置 Secrets

在 Streamlit 应用的设置中添加 Secrets：

```toml
DEEPSEEK_API_KEY = "your_api_key_here"
DEEPSEEK_BASE_URL = "https://api.deepseek.com"
DEEPSEEK_MODEL = "deepseek-chat"
```

保存后，应用会自动重启并读取线上配置。

## 使用流程

1. 打开应用页面
2. 选择关卡类型
3. 填写关卡场景、目标、难度、敌人类型和核心机制
4. 点击生成关卡方案
5. 查看 AI 生成的关卡设计文档
6. 查看评分结果和问题分析
7. 根据需要点击一键优化
8. 导出 Markdown 文档
9. 在历史记录中查看过往生成内容

## 项目亮点

### 1. 面向具体垂直场景

本项目不是通用聊天工具，而是针对游戏关卡设计流程进行设计，输出结果更接近策划文档。

### 2. 使用固定策划模板

AI 生成内容受到结构化模板约束，避免完全自由发挥，使输出内容更稳定，也更适合用于作品集展示。

### 3. 加入评分与优化流程

项目不仅生成方案，还会对方案进行评审，并根据问题给出优化建议，形成“生成、评价、修改”的完整闭环。

### 4. 支持多种 2D 关卡类型

项目目前支持潜入、平台跳跃、解谜、动作战斗和探索冒险五种类型，后续可以继续扩展更多模板。

### 5. 适合继续拓展

后续可以加入关卡地图可视化、PDF 导出、Unity 数据导出、方案对比和多人协作等功能。
