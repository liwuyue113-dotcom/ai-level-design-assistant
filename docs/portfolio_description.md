# AI 关卡设计助手 —— 作品集项目说明

---

## 一、项目背景

在游戏开发中，关卡设计是最核心的策划工作之一。传统关卡设计流程依赖策划人员手动撰写文档、反复测试调整，效率较低。随着大语言模型（LLM）的发展，AI 辅助游戏策划成为新的可能性。

本项目旨在探索：**AI 能否在游戏策划的专业场景中，生成符合行业标准的关卡设计方案？** 我们选择 2D 游戏作为切入点，因为 2D 关卡结构清晰、设计方法论成熟，非常适合展示 AI 辅助策划的能力和边界。

---

## 二、项目目标

1. 构建一个面向 2D 游戏的 AI 关卡设计辅助工具
2. 支持 5 种主流 2D 关卡类型：潜入、平台跳跃、解谜、动作战斗、探索冒险
3. 实现「生成 → 评分 → 优化」的完整策划工作流
4. 输出符合游戏策划行业标准的文档格式
5. 项目代码结构清晰，适合作为作品集展示

---

## 三、我的职责

作为项目的设计者和开发者，我完成了以下工作：

- **需求分析**：梳理 5 种 2D 关卡类型的设计方法论，确定每种类型的核心设计要素
- **Prompt Engineering**：设计 8 套专业 Prompt 模板，确保 AI 输出符合策划文档标准
- **全栈开发**：使用 Python + Streamlit 构建完整的 Web 应用
- **服务设计**：实现 API 调用层、数据持久化、文档导出等服务模块
- **评分系统设计**：针对不同关卡类型设计了动态评分维度和权重
- **项目文档**：撰写 README、代码注释和作品集说明

## 四、核心功能

### 1. 关卡方案生成
用户选择关卡类型并输入参数（场景、目标、难度、敌人类型等），AI 按照专业策划文档格式生成包含以下章节的完整方案：
- 关卡主题、玩家目标、地图区域划分
- 核心路线设计、敌人/障碍配置、奖励配置
- 失败条件、玩家体验节奏、交互物与机制设计、设计意图

### 2. 多维度自动评分
AI 以「关卡评审专家」角色对方案打分（满分 100 分），五类关卡各有独立的评分维度：
- **潜入**：路线选择、风险收益、敌人巡逻、隐藏路线、目标、节奏
- **平台跳跃**：跳跃节奏、平台布局、难度曲线、检查点、陷阱、重试体验
- **解谜**：谜题目标、提示充分性、解谜步骤、玩家反馈、机关设计、难度递进
- **动作战斗**：敌人组合、战斗节奏、补给、战斗空间、波次、Boss 设计
- **探索冒险**：区域连接、探索奖励、隐藏内容、环境叙事、支线目标、探索动机

### 3. 智能优化
AI 根据评分结果和问题分析，自动生成优化方案，并附修改说明、优化理由和预期评分提升。

### 4. 文档导出与历史管理
支持一键导出 Markdown 格式的完整文档，所有生成记录保存在本地 JSON 文件中。

## 五、技术实现

| 层次 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Streamlit | 纯 Python Web 框架，快速构建专业 UI |
| AI | DeepSeek API | OpenAI 兼容接口，中文能力强 |
| 存储 | JSON 文件 | 轻量级本地持久化，无需数据库 |
| 导出 | Markdown | 通用文档格式，易于版本管理和展示 |
| 配置 | python-dotenv | 环境变量管理，API Key 安全存储 |

**项目结构**遵循分层架构：
- `prompts/` — Prompt 模板层（按关卡类型拆分）
- `services/` — 业务逻辑层（API 调用、存储、导出）
- `app.py` — 表示层（Streamlit UI）

## 六、策划价值

这个项目展示了我对以下游戏策划概念的理解和实践：

1. **关卡类型方法论**：深入理解 5 种 2D 关卡类型的设计重点和差异
2. **多路线设计**：安全路线、危险路线、隐藏路线的风险收益平衡
3. **玩家体验节奏**：紧张-喘息-高潮-收尾的节奏控制
4. **评分体系构建**：从策划角度量化评估关卡质量
5. **迭代优化思维**：基于评分结果进行针对性改进

---

## 七、项目亮点

- **不只是聊天机器人**：输出的是结构化的专业策划文档，而非随意聊天
- **类型化设计**：针对 5 种关卡类型的差异化 Prompt 和评分体系
- **完整工作流**：生成 → 评分 → 优化，涵盖策划工作全流程
- **可展示性强**：支持 Markdown 导出，方便整理进作品集
- **代码质量**：分层架构、异常处理、中文注释
